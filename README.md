🌟 What is Netcraft Lab?
Netcraft Lab · 网络工坊 不只是一个学习项目，它是一个网络工程师的成长实验室。
在这里，我将：
🔬 实验 - 动手实践每一个网络技术
📚 学习 - 系统性构建网络知识体系
✍️ 输出 - 将所学转化为可分享的知识
🚀 成长 - 从新手走向网络专家
"Talk is cheap. Show me the lab."
"空谈误事，实验为证。"

📌 项目定位
本仓库致力于：
📚 系统整理 CCNA / CCNP / CCIE 各阶段实验内容
🧪 提供可复现的 Lab 拓扑与配置
🔍 深入解析关键技术点与原理
🛠️ 分享真实工程场景中的设计思路
🌐 构建一个长期更新的网络技术知识库

🧪 实验环境支持

本项目支持以下主流实验平台：

🖥️ EVE-NG
🌐 GNS3
☁️ Cisco CML
🐳 Container-based Labs（部分自动化实验）
